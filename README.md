# Kairav Sharma — Portfolio

Single-page portfolio site for Kairav Sharma, freelance full-stack developer.

- Pure HTML + inline CSS/JS — no build step, no dependencies.
- Deployed as a static site on Vercel.

## Run locally

Open `index.html` in a browser, or serve it:

```
npx serve .
```

## Deploy

```
vercel --prod
```

## Notes

- "Hire me" / "Email me" buttons open a pre-filled email to `sharmakairav27@gmail.com`.
  If the visitor has no desktop mail app, the buttons fall back to Gmail web compose.
- To change the contact address, edit the `TO` constant in the `<script>` block in `index.html`.
